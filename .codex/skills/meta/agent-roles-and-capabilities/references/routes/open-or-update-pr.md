# Open or Update PR Route

Read when the user explicitly authorizes pushing a clean committed feature branch and creating or updating its pull request.

```txt
Primary role: PR Manager
Supporting roles: Tooling Reviewer, Documentation Writer as needed
Workflow: open-or-update-pr
Maturity expectation: exact branch/PR identity, fail-closed preflight, and verified external state
Technical specialist skill: no technology-specific skill required
Quality rule: engineering-quality-principles applies to tooling and workflow changes
```
